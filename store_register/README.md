# 네이버지도 → 레빗가이드 정보입력
네이버지도에서 식당 정보를 가져와서 레빗가이드에 자동으로 입력해주는 프로그램입니다.

## 🚀 사용법

### 0단계: 준비
- 파이썬 설치
- naver_to_revitguide.py 파일 다운받기 (혹은 git clone)
- requirements.txt에 있는 패키지 설치

### 1단계: 터미널에서 프로그램 실행
```
python3 naver_to_revitguide.py #Mac
```
파일있는 경로에서 실행 or 경로포함 파일명 입력

### 2단계: 네이버지도 링크 입력
- 네이버지도에서 등록하고 싶은 식당을 찾습니다
- 주소창의 링크를 복사해서 붙여넣습니다 이 때 중요한 정보는 place/{숫자}?에서 {}괄호 안에 위치한 숫자입니다
- 예: https://map.naver.com/p/entry/place/1695035303?

### 3단계: 자동 처리 기다리기
프로그램이 자동으로 다음 작업들을 진행합니다:
- ✅ 식당 정보 수집
- ✅ 레빗가이드 로그인 (첫 실행시에만 구글 로그인 필요)
- ✅ 식당명, 주소 자동 입력
- ✅ 영업시간 자동 입력
- ✅ 정기휴무 자동 설정

### 4단계: 누락 정보 직접 입력
- **지점명**: 식당명에 같이 입력된 지점명 텍스트 지점명 필드로 옮기기
- **음식 장르**: 직접 입력
- **기타 정보**: 필요시 추가 정보 입력

### 5단계: 등록 완료
- 정보를 확인하고 등록 버튼을 눌러 완료합니다

## 📝 필수입력 항목

| 입력 항목 | 자동 여부 | 비고 |
|-----------|-----------|------|
| **식당명** | ✅ 자동 | 지점명까지 포함되므로 확인 필요 |
| **지점명** | ❌ 수동 | 식당명에서 오려붙이는편 분리로직 짜려다 예외가 많을 것 같기도하고 등록 전에 확인도 해야해서 구현안함 |
| **주소** | ✅ 자동 | 1. 주소검색 후 처음으로 나오는 위치 자동클릭 <br> 2. 1이 실패할경우 input창에 주소 붙여넣기. 주소텍스트와 지도 대략적 위치 확인 필요 |
| **영업시간** | ✅ 자동 | 데이터 파싱로직에 반영되지않은 예외상황 발생시 오류날 가능성 존재 |
| **브레이크타임** | ✅ 자동 | (동일) |
| **라스트오더** | ✅ 자동 | 현재로직은 라스트오더 시간 2개면 제일 나중시간으로 입력 |
| **정기휴무** | ✅ 자동 | (동일) |
| **음식 장르** | ❌ 수동 | 직접 입력 필요 |

## 작동로직

1. url 입력하면 식당 기본 정보 크롤링해옴
2. 크롤링한 정보를 영업시간, 정기휴무로 파싱해서 로컬에 저장 (등록할 때 오류가 났다면 반복적 크롤링 피할 수 있음) 캐시 데이터 유효성 체크 진행(필수항목: 이름, 주소, 영업시간)
3. 정보를 가지고와서 다시 레빗가이드 등록하기 쉬운 형태로 가공
	time_block (요일별로 같은 영업시간/브레이크타임/라스트오더 모아서 처리)
	holiday_block (정기휴무 등록용 블록)
4. 로그인 혹은 저장된 세션이 유효하다면 자동 로그인
5. 식당등록 페이지에서 정보가 자동입력됨
6. 반복. 
    만약 브라우저를 닫았다면 네이버지도 크롤링 이후 등록절차에서 오류 발생. 이때는 파이썬 프로그램 종료 후 재시작 하면 됩니다

## 🔐 보안 주의사항

### 개인정보 보호
- 로그인 세션이 `~/.revitguide_session.json`에 저장됩니다
- 캐시 정보가 `~/.naver_revit_cache.json`에 저장됩니다
- **개인 컴퓨터에서만 사용하세요**
- **공용 컴퓨터 사용 금지** (세션 정보 노출 위험)

### 세션 관리
- 세션은 자동으로 만료되지 않습니다
- 필요시 수동으로 삭제:
```bash
# 세션 파일 삭제
rm ~/.revitguide_session.json

# 캐시 파일 삭제  
rm ~/.naver_revit_cache.json
```

### 사용 제한
- **개인적 용도로만 사용**
- **대량/상업적 이용 금지**
- 네이버 이용약관 및 레빗가이드 이용약관 준수
- 하루 적정 사용량 권장 (과도한 크롤링 자제)
